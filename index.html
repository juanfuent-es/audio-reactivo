Teoría mínima

Amplitud

p5.Amplitude() mide el volumen global. Se puede mapear a escala, grosor u opacidad.

Frecuencias

p5.FFT() divide la señal en un arreglo. En esta versión, fft.analyze() devuelve energía entre 0 y 1.

Forma de onda

fft.waveform() devuelve muestras entre −1 y 1 para dibujar la señal en el tiempo.

Cargar, analizar y dibujar

Los ejercicios comparten js/audio-playback.js. Este archivo carga la canción y controla la reproducción; cada visualización interpreta sus propios datos.

let song;
let fft;

async function setup() {
  createCanvas(windowWidth, windowHeight);
  song = await audioPlayback.load();
  fft = new p5.FFT(64);
  song.connect(fft);
}

async function mousePressed() {
  await audioPlayback.toggle(song);
