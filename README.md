# CENTRO.audio-reactive

Ejemplos actualizados para `p5@2.3.3` y `p5.sound@0.4.1`.

Ejecuta el proyecto desde `localhost` o HTTPS. El acceso al micrófono no es
fiable desde una URL `file://`. Las librerías se cargan desde jsDelivr con una
versión fija y los recursos usan el flujo `async`/`await` de p5.js 2.
